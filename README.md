# Attrition-Rate-Analysis

Attrition Rate was a major problem to many of the organizations during the pandemic. By this analysis I was able to : 
1) Identify Key Factors: Analyzed how variables like distance from home, job satisfaction, and monthly income influence attrition.
2) Explore Attrition Trends: Grouped employees based on seniority, department, and work-life balance to identify patterns.
3) Apply Statistical & ML Models: Used techniques such as logistic regression and feature importance analysis to predict attrition.
4) Utilize Data Visualizations: Created heatmaps and bar charts to visually interpret attrition trends.
5) Derive Actionable Insights: Provided data-driven recommendations to mitigate attrition based on high-impact factors.
